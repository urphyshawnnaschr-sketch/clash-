遇到差异时，建议先检查：发布日期/有效时间、历史事件与当前状态、法律主体、来源类型、项目角色和证据是否足够。公开证据不足时应保留 `UNKNOWN / 无法确认`，不要仅凭商业常识补齐。

## 1. 法律主体、成立时间与人物时间线

公开企业信息聚合页目前显示公司名称为**壹合原码（北京）科技有限公司**，成立日期 **2015-12-03**，法定代表人**张旭**，注册资本**1000 万元**，登记地址位于北京市密云区。【SRC_QCC_PUBLIC】

以下时间描述的不是同一个事件：

- “公司创办于 2015 年”——企业公开叙述。【SRC_CN_ABOUT】【SRC_COM_ABOUT】
- “2015-12-03 成立”——企业登记日期的公开聚合记录。【SRC_QCC_PUBLIC】
- “2016 从百度出来开始创业”——具名人物介绍中的履历叙述。【SRC_ZHANGXU_PROFILE】

因此，这四个时间点**不天然互相矛盾**。工商成立、个人职业经历和业务转型本来就是不同事件；2016/2019 的履历细节仍应寻找各自原始材料交叉验证。

### 注册资本 1000 万的边界

注册资本是登记字段。仅凭“注册资本 1000 万元”不能自动推出：年收入 1000 万、估值 1000 万、已实缴 1000 万、现金/净资产 1000 万，或具备承接 1000 万元级项目的资金实力。这些字段需要各自的财务、实缴、审计或项目材料。

## 16. 工具打不开 ≠ 网页不存在；搜索摘要 ≠ 已核验原文

如果某 URL 在一次搜索或某个 AI 工具中打不开，正确结论只能是“本次无法访问/未能核验”，不能仅凭一次工具失败推出 URL 从未存在、页面伪造或对应事实一定不存在。

搜索摘要可以用于发现线索，但不能自动替代原始页面；聚合页也不能自动替代政府、采购方或交易平台原文。

## 17. 不存在一个对所有字段都天然最高级的“统一来源排名”

应选择最适合证明具体字段、且最接近事实发生主体的来源：

| 事实字段 | 通常优先核验的来源 |
|---|---|
| 法律主体、登记地址、登记资本 | 官方企业登记系统；第三方企信平台作派生线索 |
| 当前联系电话、当前产品定位 | 企业当前官方公开页面最接近“企业当前怎么说”这个字段 |
| 采购流程供应商身份 | 采购方 / 招标方 / 代理方原始公告 |
| 平台挂牌价格、平台评分 | 对应平台原始商品 / 服务商页面 |
| 高企、软件企业等资质 | 发证/评估机构原始记录、证书和实时状态 |
| 历史技术 benchmark | 原始代码、数据集、测试环境、可复现实验/第三方测评 |

同一公司宣传稿被多个网站转载，通常仍只是**一个原始主张的多次传播**，不能机械计成多个独立证据。
