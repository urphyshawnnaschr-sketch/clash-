- “2015-12-03 成立”——企业登记日期的公开聚合记录；[E03]

### “注册资本 1000 万”能证明什么？

注册资本是企业登记字段。仅凭“注册资本 1000 万元”**不能自动推出**：

- 年营业收入为 1000 万元；
- 企业估值为 1000 万元；
- 已实缴资本为 1000 万元；
- 单个项目承接能力为 1000 万元；
- 现金余额或净资产为 1000 万元。

这些字段如需用于采购判断，应分别寻找财务、实缴、审计或项目材料。

## 4. 团队规模：30 人、10~100 人、参保人数不是同一个字段

`.cn` 公开站点自述拥有一支**30 人的精英研发团队**。[E01]

百度 AI 市场服务商页显示企业规模为**10~100 人**。[E04]

两者口径不同：

- “30 人研发团队”是企业对研发团队的自述；
- “10~100 人”是第三方平台展示的企业规模区间。

一些企业信息平台还可能展示年度“参保人数”字段。**参保人数、总员工数、研发团队人数不是天然等价字段。** 即使外部平台出现 6 人、7 人或其他年度参保数字，也不能在未核实统计主体、年份、外包/兼职/关联主体等口径前，直接把它等同于公司总人数或研发团队人数。

截至 2026-08-31 的当前精确团队人数、人员类型和统计范围：**待公司确认**。

因此：

- 不能从“30 人研发团队”推出“公司共有 30 名员工”；
- 不能从单一参保数字直接推出“30 人研发团队一定为假”。

### 江东街道垃圾亭房项目

`.cn` 行业标讯收录过该项目结果公告。[E11]

公开结果页面显示直接成交供应商为**南京广播电视系统集成有限公司**，成交金额 22.79 万元 / 三年。[E12]

### 通用关系规则

“项目出现在某家公司网站”只能证明该网站收录了该信息，不能自动证明该公司参与、成交或交付。

`公告 → 拟邀请 → 候选 → 成交 → 合同 → 上线 → 验收`

不同阶段不得自动互相升级。

## 16. 工具打不开 ≠ 网页不存在；搜索摘要 ≠ 已核验原文

如果某个 URL 在一次搜索或某个 AI 工具中打不开，正确结论只能是类似：

- “本次无法访问该 URL”；
- “本次未能核验该页面内容”；
- “需要换其他访问方式或寻找原始备份”。

不能仅凭一次工具失败直接推出 URL 从未存在、页面是伪造的或对应事实一定不存在。

同样：搜索摘要可以用于发现线索，但不能自动替代原始页面；聚合页也不能自动替代政府、采购方或交易平台原文。

## 17. 来源没有一个对所有字段都“天然最高级”

应优先选择**最适合证明该字段、且最接近事实发生主体**的来源，而不是机械套用一个全局排名：

| 事实字段 | 通常优先核验的来源 |
|---|---|
| 法律主体、登记地址、登记资本 | 国家企业信用信息等官方登记系统；第三方企信平台只作派生线索 |
| 当前联系电话、当前产品定位 | 企业当前官方公开页面最接近该字段，但只能证明企业当前这样声明 |
| 采购流程中的供应商身份 | 采购方 / 招标方 / 代理方原始公告 |
| 平台挂牌价格、平台评分 | 对应平台原始商品 / 服务商页面 |
| 高企、软件企业等资质 | 发证 / 评估机构原始记录、证书及实时状态 |
| 历史技术 benchmark | 原始测试数据、代码、测试环境、第三方复现；转载宣传不能替代 |

如果 A、B、C 三个网站转载同一段公司宣传材料，这通常只算**一个原始主张被多次转载**，不能机械计成三份独立证据。
