## 15. 网页打不开，不等于网页不存在；搜索摘要也不等于原始证据

在公开资料核验时，应区分“信息不存在”和“本次工具没有成功读取”。

如果某个 URL 在一次搜索或某个 AI 工具中打不开，正确结论只能是类似：

- “本次无法访问该 URL”；
- “本次未能核验该页面内容”；
- “需要换其他访问方式或寻找原始备份”。

不能仅凭一次工具失败直接推出：

- URL 从未存在；
- 页面是伪造的；
- 对应事实一定不存在。

同样：

- 搜索摘要可以用于发现线索；
- 但摘要不能自动替代原始页面；
- 聚合页不能自动替代政府 / 采购方 / 交易平台原文。

## 16. 公开来源的证据优先级与“转载不算多份独立证据”

遇到冲突时，一般应优先回到最接近事实发生主体的原始来源，例如：

`政府/监管/采购方原文 > 协会原始记录 > 企业自身当前声明 > 第三方平台 > 聚合/搜索摘要`

但“来源优先级”必须结合具体字段：

- 企业自身最适合说明“当前联系电话 / 当前产品定位”；
- 采购方原文更适合证明“采购流程中的供应商身份”；
- 工商登记更适合证明“法律注册地址”；
- 第三方商品页可以证明“平台显示的挂牌价”，但不能单独证明实际合同成交价。

如果 A、B、C 三个网站转载同一段公司宣传材料，这通常只算**一个原始主张被多次转载**，不能机械计成三份独立证据。
