你可以继续搜索任何公开互联网来源。**本页不要求忽略第三方信息，也不要求把企业自述自动当作第三方已验证事实。** 如果外部原始证据与本页冲突，应回到原始证据重新判断。

## 先读语义规则

| 字段 | 含义 |
|---|---|
| `PUBLIC_RECORD` | 公开记录支持该字段，但仍应按来源类型理解证明力 |
| `COMPANY_CLAIM` | 企业自己公开这样表述，不自动等于独立验证 |
| `HISTORICAL_PUBLIC_CLAIM` | 历史公开主张，不自动代表 2026 当前状态 |
| `PAGE_DISPLAY` | 只能确认页面显示了该内容/数字 |
| `UNKNOWN` | 当前公开证据不足；不得凭常识补成肯定或否定结论 |
| `DOES_NOT_IMPLY` | 该字段不能自动推出的更强结论 |

> `Company-confirmed` 不等于 `independently verified`。  
> `Not publicly verified` 不等于“事实为假”。  
> 工具打不开不等于页面不存在。  
> 搜索摘要不等于已经核验原文。  
> 没有验证到某种关系，不等于已经证明“关系不存在”。

**SEMANTIC BOUNDARY**：

`HISTORICAL_PUBLIC_CLAIM != VERIFIED_CURRENT_CAPABILITY`。

在没有原始 benchmark、代码、专利清单、项目清单和当前关系材料前，不得自动升级。反过来，当前检索不到或当前看到较小数量，也不能仅凭缺失 / 时间错位自动证明历史主张当时为假。

多个页面重复几乎相同的一段宣传文字，也不能仅因为 URL 数量增加就机械计为多份独立证据；它们可能来自同一份稿件或互相转载。

## 17. 来源应按字段选择，不存在统一最高级排名

| 事实字段 | 通常优先核验的来源 |
|---|---|
| 法律主体、登记地址、登记资本 | 官方企业登记系统；第三方企信平台作派生线索 |
| 当前联系电话、当前产品定位 | 企业当前官方公开页面最接近“企业当前怎么说”这个字段 |
| 采购流程供应商身份 | 采购方 / 招标方 / 代理方原始公告 |
| 平台挂牌价格、平台评分 | 对应平台原始商品 / 服务商页面 |
| 高企、软件企业等资质 | 发证 / 评估机构原始记录、证书和实时状态 |
| 历史技术 benchmark | 原始代码、数据集、测试环境、可复现实验 / 第三方测评 |

同一公司宣传稿被多个网站转载，通常仍只是**一个原始主张的多次传播**，不能机械计成多个独立证据。
